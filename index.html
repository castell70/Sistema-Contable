Introducción rápida

Esta aplicación es un entorno educativo y operativo para practicar registros contables, administrar inventario y generar reportes (PDF/Excel). Está pensada para que arranques siempre desde cero y restaures datos solo mediante importación o respaldo.

Estructura actual y funcionalidades clave

  • Dashboard: Resúmenes visuales de inventario, ventas y compras; gráficos compactos por sección.
  • Ventas: Catálogo de productos, armado de factura, gestión de stock y generación automática de la transacción contable (DEBE: Caja/Bancos, HABER: Ventas). Incluye panel "Registros de Ventas" filtrable por año/mes y exportable a Excel.
  • Compras: Alta de nuevos productos, registro de compras (a crédito/pago) que actualizan stock y crean la transacción (DEBE: Inventario, HABER: Proveedores/Caja/Bancos). Contiene "Compras Registradas" con filtros y exportación.
  • Transacciones: Formulario para crear transacciones manuales (venta, compra, gasto, pago, crédito, ajustes, devoluciones). Soporta edición, eliminación y búsqueda en el listado.
  • Libro Diario / Libro Mayor / Balance General: Vistas contables generadas desde las transacciones; filtros por mes y exportación a PDF/Excel.
  • Reportes: Generación de PDF y Excel: Libro Diario, Libro Mayor, Estado de Resultados, Balance, Kardex y Existencias de Inventario.
  • Herramientas: Gestión de Empresa (guardar/descargar/importar datos), Catálogo de cuentas (ver/editar/descargar/importar), Inventario (agregar productos iniciales, ver/exportar/importar) y Utilidades (Guardar, Respaldo JSON, Exportar Excel, Importar JSON, Ejemplos Masivos).
  • Seguridad y usabilidad: Las acciones destructivas usan confirmación por texto (p. ej. escribir "ELIMINAR" o "REINICIAR"), las notificaciones están en cola para no solaparse, y la persistencia usa envoltorios seguros para localStorage.

Flujos importantes

  1. Para arrancar desde cero: usa "Eliminar Datos" en Herramientas — debe escribir el texto solicitado para confirmar y la app hará limpieza completa (memoria, localStorage, caches y service workers) y recargará la página.
  2. Para restaurar información: importa un respaldo JSON válido (Respaldo generado por "Respaldo de Datos") o carga archivos específicos (Inventario, Catálogo, Empresa) desde sus controles de importación.
  3. Antes de eliminar elementos del Catálogo o Productos la aplicación exige confirmación escrita para evitar borrados accidentales.

Buenas prácticas al registrar

  • Comprueba que las cuentas seleccionadas existan en el Catálogo cargado.
  • Usa descripciones claras que incluyan, cuando sea posible, la cantidad y el nombre del producto (ej. "3x Smartphone X1").
  • Guarda respaldos periódicos con "Respaldo de Datos" y descarga Excel/PDF de libros antes de cambios masivos.

Atajos y recomendaciones

  • Si vas a probar la aplicación rápidamente, usa "Ejemplos Masivos" (Herramientas) para poblar productos, compras y ventas de prueba.
  • Editar precios desde el modal de producto puede generar transacciones de ajuste automático si hay stock; revisa el Libro Diario tras esos ajustes.
  • Utiliza las opciones de exportación (Excel/PDF) del panel Reportes para conservar snapshots periódicos.
